Propuesta interactiva · Sin conexión a Grafana k6 ni solicitudes al destino.PULSE LAB / PERFORMANCE, EXPLAINED.

De una URL a una respuesta.

Pulse es una propuesta de interfaz para convertir resultados de Grafana k6 en decisiones claras. Esta versión es completamente simulada.

  • API / Endpoint: configura método, headers y body; compara concurrencia, throughput, latencia y errores.
  • Web Browser: simula navegación con Chromium y consulta LCP, CLS y duración. Los VUs de navegador cuestan más recursos que los VUs HTTP.
  • Carga gradual: sube, mantiene y baja. Constante: carga sostenida. Pico: subida repentina. Estrés: aumenta hasta el máximo configurado.
  • Capacidad: aquí es una fórmula ilustrativa. En producción debe derivarse de pruebas repetidas y de los umbrales de tu negocio, no de una sola ejecución.
  • Siguiente fase: runner k6 aislado, cola de ejecuciones, destinos autorizados, límites de carga, secretos cifrados y almacenamiento de resultados con comparación de regresiones.

Una URL permite probar navegación básica. Un flujo real de login o checkout requiere definir pasos, selectores, datos y validaciones. INP necesita interacciones; no se inventa para una navegación simple.
